# API REST de Gerenciamento de Produtos

API REST desenvolvida em **Spring Boot** para o gerenciamento de produtos, utilizando persistência em memória com **H2 Database** e validação de dados via Bean Validation.

---

## 🛠️ Tecnologias Utilizadas

* **Java 21**
* **Spring Boot 3.2.5**
* **Spring Data JPA**
* **Spring Boot Starter Validation**
* **H2 Database (In-Memory)**
* **Maven**

---
